# Astro-Space

A free-first, faceless, music-driven astronomy short-video project.

## Current milestone

Milestone 1: visual style configuration.

The canonical style settings are in `config/visual_style.json`.

## Current creative specification

- 9:16 vertical video, 1080x1920, 30 fps
- 15–30 seconds, target 22 seconds
- 5–9 real astronomy/science images per video
- Slow cinematic zoom/pan, mostly crossfades
- Music only; no narration or explanatory text
- Target: 3 videos per day
- Manual review is mandatory; automatic publishing is disabled

## Non-negotiable rules

1. Use only images and music with documented rights suitable for the intended use.
2. Keep source URL, creator/rightsholder, licence name, licence URL and download date for every asset.
3. Never present AI-generated imagery as authentic scientific photography.
4. Do not publish automatically. A human must approve each finished video.
5. Keep the workflow free-first. Do not add paid APIs, paid subscriptions or billing requirements.
